# DocGen — дизайн на сегодня

## Выбранный стиль

Refero: [Apple (España)](https://styles.refero.design/style/c9cabb96-32fa-4896-837a-f2497ce1c856)

## Правила реализации

- стили подключать только через Tailwind CDN;
- свои CSS не писать;
- оформлять корневой `index.html` по выбранному стилю Refero;
- сохранять один светлый, просторный интерфейс без декоративной перегруженности;
- использовать системный шрифт с fallback `Inter, system-ui`;
- держать основной текст в цвете `#1d1d1f`, вторичный — `#707070`;
- использовать белый `#ffffff` и светло-серый `#f5f5f7` как чередующиеся поверхности;
- использовать `#0071e3` только для основных CTA-кнопок, а `#0066cc` — для текстовых ссылок;
- оформлять карточки с радиусом около `28px`, кнопки — в форме pill;
- не использовать тени и тяжёлые видимые границы для разделения блоков;
- оставлять много свободного пространства и строить иерархию типографикой.

## Применение к прототипу

Стиль применяется ко всему основному сценарию из [docs/UX.md](UX.md): источники, настройка шаблона и формата, сборка, проверка по шаблону, чат и выгрузка новых материалов.
