# Локальная конфигурация LiteLLM

## Цель

Подключить DocGen к корпоративному OpenAI-совместимому LiteLLM endpoint для текстовой модели, не сохраняя API-ключ и другие секреты в Git.

## Конфигурация

- `Settings` должен загружать `.env` из корня репозитория независимо от текущего рабочего каталога процесса.
- В корневом `.env` локально сохраняются `DOCGEN_LOCAL_TEXT_BASE_URL`, `DOCGEN_LOCAL_TEXT_MODEL`, `DOCGEN_LOCAL_TEXT_API_KEY` и `DOCGEN_TRUSTED_INTEGRATION_HOSTS`.
- Доверенный список содержит корпоративный хост AI endpoint.
- Значения секретов нельзя выводить в команды проверки, логи, тесты, документацию или Git diff.

## Запуск

После изменения конфигурации web и worker перезапускаются, чтобы получить новые переменные. Существующий локальный worker ID сохраняется.

## Проверка

- Регрессионный тест подтверждает, что `Settings` читает корневой `.env`, даже если процесс запущен из `app`.
- `git check-ignore` подтверждает исключение `.env` из Git.
- Конфигурация проверяется без печати значений: только наличие URL, модели и ключа и прохождение политики доверенного хоста.
- Выполняется минимальный структурированный запрос через адаптер DocGen; содержимое запроса, ответа и ключ не выводятся.

## Ограничения

- Настраивается только текстовая модель. Vision-модель и Confluence не меняются.
- Спецификация и код могут храниться в Git; корневой `.env` остаётся исключительно локальным.
