# Formatta: развёртывание в Dockploy

## Цель

Подготовить Formatta к внутреннему развёртыванию через Dockploy, сохранив
существующий локальный запуск Docker Compose без изменений.

## Решение

В репозитории будет отдельный `docker-compose.dokploy.yml`. Он запускает те
же сервисы `web` и `worker` из одного образа, использует общий именованный
volume `formatta-var` для SQLite и загруженных файлов и не публикует порт
напрямую на хост. Сервис `web` объявляет `expose: 8000`; публичный домен в
Dockploy направляется на этот сервис и порт 8000 через встроенный proxy.

`web` получает HTTP healthcheck на `/health`. `worker` зависит от успешного
healthcheck web, чтобы не стартовать до инициализации базы. Оба сервиса
перезапускаются Dockploy/Docker через `unless-stopped`. Одна копия web и одна
копия worker — обязательное ограничение MVP с SQLite.

## Конфигурация и безопасность

Секреты не входят в образ или Git. Dockploy записывает заданные в UI
переменные в свой `.env`; compose подключает его через `env_file: .env`.
Обязательны URL и модель локального text endpoint, ключ при необходимости и
список доверенных хостов. Vision и Confluence необязательны. `DOCGEN_DATA_DIR`
и `DOCGEN_DATABASE_URL` указывают только на общий volume.

Порт 8000 не пробрасывается через `ports`, поэтому доступ пользователей
возможен только через домен Dockploy. В Dockploy домен привязывается к
сервису `web`, container port `8000`. Приложение развёртывается только во
внутреннем контуре: встроенной авторизации в MVP нет.

## Проверка

Тест загрузит оба compose-файла YAML. Он защитит: отсутствие `ports` в
Dockploy compose, наличие `expose: 8000`, healthcheck `/health`, общую
персистентность, конфигурацию worker и зависимость от `service_healthy`.
README опишет точные действия в Dockploy и ручную post-deploy проверку
`/health` и `/projects`.

## Вне области

Не меняются приложение, модель данных, авторизация, Dockerfile и локальный
`docker-compose.yml`. Не выполняется сам deploy и не создаётся домен: это
действия в корпоративной панели с секретами и правами пользователя.
