# HTML-экспорт результата в шаблоне страницы v5

## Цель

Экспортировать сохранённый результат редактора в автономный HTML-файл,
сохраняя поддерживаемые редактором текст, rich-форматирование и стили и
оформляя документ по образцу
`Материалы/Шаблоны/Шаблон страницы/versions/v5/one-page-course-template.html`.

Изменение ограничено HTML-экспортом. Интерфейс DocGen, редактор, сборка и
проверка документов, а также экспорт в DOCX, PDF и Markdown не меняются.

## Источник данных

Экспорт использует `WorkingDocument` конкретной сохранённой ревизии, которую
уже получает существующий `ExportService`. Отдельное чтение сырого
`workspace_html` не добавляется.

Для сохранения оформления используются канонические данные редактора:

- `node.data["html"]` для rich-текста заголовков и абзацев;
- `node.data["items_html"]` для элементов списков;
- нормализованные стили узла и элементов списка;
- структурированные поля таблиц и изображений;
- обычный `node.text` или `items` как безопасный fallback.

## Формирование страницы

HTML-шаблон v5 адаптируется в Jinja-шаблон каталога форматирования DocGen.
Демонстрационный текст из исходной страницы в экспорт не попадает.

- Название документа используется в `<title>` и верхней hero-карточке.
- Заголовки первого уровня формируют самостоятельные карточки-разделы.
- Блоки после заголовка входят в его карточку до следующего заголовка того же
  уровня.
- Более глубокие заголовки остаются внутри текущего раздела.
- Контент до первого раздела выводится во вводной карточке.
- Документ без разделов выводится одной карточкой.
- При наличии минимум двух разделов создаётся карточка оглавления с якорными
  ссылками.
- Якоря строятся детерминированно, безопасны для HTML и уникальны при
  одинаковых заголовках.

Поддерживаются существующие типы узлов: заголовок, абзац, список, таблица,
изображение и пробел в данных. Вложенные узлы выводятся рекурсивно.

## Оформление и автономность

В экспорт переносится визуальный язык v5: hero-блок, белые карточки,
корпоративные цвета, типографика, интервалы, таблицы, списки и кнопка возврата
к оглавлению или началу страницы.

Итоговый файл не обращается к сети:

- Bootstrap и Bootstrap Icons через CDN не подключаются;
- необходимые правила раскладки v5 включаются в локальный CSS экспорта;
- шрифты v5 встраиваются как `data:` URL;
- стрелка возврата реализуется встроенным SVG;
- изображения документа встраиваются существующим безопасным загрузчиком.

HTML остаётся адаптивным и пригодным для печати.

## Безопасность и ошибки

Rich-HTML проходит очистку на границе HTML-экспортёра. Разрешаются только
поддерживаемые редактором безопасные inline-теги, ссылки без опасных схем и
нормализованные стилевые свойства. Скрипты, обработчики событий, внешние
ресурсы и неподдерживаемые атрибуты не переносятся.

Недоступное изображение заменяется стандартной заглушкой. Отсутствующий или
повреждённый ресурс шаблона завершает только задание экспорта понятной
ошибкой; документ, проект и ранее созданные файлы не изменяются.

## Область изменений

Допустимы изменения только в следующих местах:

- `app/src/docgen/export/html.py`;
- HTML-манифест и ресурсы шаблона в
  `app/src/docgen/formatting/templates/`;
- тесты HTML-экспортёра и, только при необходимости проверки полного
  сценария, существующие тесты HTML-маршрута/экспортного сервиса.

Не допускаются изменения интерфейсных шаблонов DocGen, JavaScript редактора,
моделей документа, маршрутов других функций и реализаций других форматов.

## Проверка

Тесты должны подтвердить:

- перенос rich-текста, допустимых стилей и выравнивания;
- перенос rich-элементов и индивидуальных стилей списков;
- корректный вывод таблиц, изображений, пробелов и вложенных узлов;
- формирование карточек и условного оглавления;
- детерминированные уникальные якоря;
- fallback на plain text при отсутствии rich-данных;
- удаление XSS, опасных ссылок и внешних ресурсов;
- встраивание CSS, шрифтов и изображений в один автономный файл;
- сохранение имени файла, UTF-8 и текущего поведения открытия HTML;
- отсутствие регрессий в существующих тестах экспорта.
