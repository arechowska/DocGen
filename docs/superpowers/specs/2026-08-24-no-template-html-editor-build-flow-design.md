# Сборка HTML без смыслового шаблона через редактор

## Цель и границы

Изменить только сценарий, в котором пользователь выбирает смысловой шаблон
«Без шаблона» и выходной формат HTML. Остальные смысловые шаблоны, форматы,
сборка, проверка и существующие сценарии прямой конвертации не меняются.

Итоговый HTML оформляется существующим HTML-шаблоном страницы версии 5.

## Пользовательский сценарий

1. Пользователь создаёт проект и добавляет один файл-источник.
2. Выбирает «Без шаблона» и формат HTML.
3. При первом нажатии «Собрать» содержимое источника нормализуется и один раз
   импортируется в рабочий документ редактора.
4. Из созданной ревизии рабочего документа формируется HTML-результат.
5. Пользователь при необходимости редактирует содержимое.
6. При следующем нажатии «Собрать» текущее содержимое редактора сначала
   сохраняется как новая ревизия, после чего из этой ревизии формируется новый
   HTML. Файл-источник повторно не читается.
7. В области результата доступны две кнопки: «Открыть» и «Скачать».

## Состояния кнопки «Собрать»

Поведение определяется наличием рабочего документа редактора:

- рабочего документа нет — выполнить первоначальный импорт единственного
  источника, создать первую ревизию и запустить HTML-экспорт;
- рабочий документ есть — не обращаться к источнику, сохранить актуальное
  содержимое редактора и запустить HTML-экспорт сохранённой ревизии.

Таким образом, источник служит начальным наполнением редактора, а после первого
импорта единственным источником данных для HTML является рабочий документ.
Замена или изменение загруженного файла не изменяет редактор автоматически.

## Сохранение и согласованность ревизий

Повторная сборка должна учитывать изменения, находящиеся в интерфейсе редактора,
даже если пользователь не нажимал отдельно «Сохранить в проекте». Для этого
сборка сначала выполняет существующую операцию сохранения редактора и получает
номер созданной ревизии, а затем запускает экспорт именно этой ревизии.

Экспорт не должен использовать более старую ревизию или несохранённое значение
из другого запроса. При конфликте ревизий или ошибке сохранения экспорт не
запускается, а пользователь получает существующее сообщение об ошибке.

После обычного нажатия «Сохранить в проекте» HTML самопроизвольно не
пересобирается: формирование результата остаётся явным действием кнопки
«Собрать».

## Формирование и выдача результата

HTML создаётся существующим экспортным конвейером из точной сохранённой ревизии
`WorkingDocument` и оформляется шаблоном версии 5. Пока новая сборка выполняется,
область результата показывает существующее состояние обработки. После успешной
сборки обе кнопки относятся к одной и той же последней успешно экспортированной
ревизии:

- «Открыть» отдаёт HTML для просмотра в новой вкладке браузера;
- «Скачать» отдаёт тот же HTML как вложение и запускает стандартное сохранение
  файла браузером.

Если новая сборка завершилась ошибкой, ранее успешно созданный файл не должен
выдаваться как результат новой ревизии.

## Точечная маршрутизация

Особое поведение кнопки «Собрать» включается только при одновременном выполнении
двух условий: выбран «Без шаблона» и выбран HTML. Для других сочетаний кнопка
продолжает использовать существующие формы и маршруты:

- «Без шаблона» с другим форматом — текущая прямая конвертация;
- любой смысловой шаблон — текущая сборка по смысловому шаблону.

Две кнопки результата также добавляются только в целевой сценарий. Глобальное
поведение HTML-экспорта и панелей результатов других сценариев не меняется.

## Ошибки и ограничения

- Для первого импорта сохраняется действующее требование ровно одного
  файла-источника.
- Ошибка нормализации источника не создаёт рабочий документ и не запускает
  экспорт.
- После появления рабочего документа повторная сборка не зависит от наличия или
  доступности первоначального файла.
- Санитизация и проверка данных редактора остаются существующими; отдельный путь
  чтения сырого HTML не добавляется.
- Механизмы удаления, повторного импорта или синхронизации редактора с источником
  в эту задачу не входят.

## Проверка

Тесты должны подтвердить:

- первый запуск импортирует источник в редактор и формирует HTML версии 5;
- повторный запуск после редактирования использует текст редактора и не читает
  источник заново;
- повторный запуск сохраняет несохранённые изменения перед экспортом;
- экспорт запускается для точной новой ревизии;
- «Открыть» и «Скачать» возвращают один и тот же актуальный HTML соответственно
  inline и attachment;
- ошибки импорта, сохранения и экспорта не подменяются устаревшим результатом;
- поведение остальных форматов и смысловых шаблонов не изменилось.
